A modern, high-performance, responsive developer portfolio crafted with **HTML5, Tailwind CSS, JavaScript (ES6+), and CSS3 animations**.

## 🛠️ How to View & Run Locally

### Option 1: Direct Double Click
Simply double-click [`index.html`](file:///c:/Users/Prerna/Desktop/prerana%20patil/index.html) in your Windows File Explorer. It will immediately open in Chrome, Edge, Brave, or your default browser. No installation or build step is required!

### Option 2: Using VS Code Live Server (Recommended)
1. Open the folder `prerana patil` in VS Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and choose **"Open with Live Server"**.

## ✏️ How to Personalize Your Information

All spots where you can plug in your real links are marked with `<!-- 💡 EDIT HERE -->` comments in `index.html`:

1. **Profile Picture:**
   - Place your profile photo in `public/images/profile.jpg` (or simply as `profile.jpg` in the main folder).
   - Alternatively, open **http://localhost:8080** and click the **camera icon 📷** directly on the avatar to select your photo file from your computer!
   - Both the **Hero section** and the **About Me section** will automatically display your photo framed with glowing blue/purple gradient borders, `object-fit: cover`, and hover animation.

2. **Resume PDF:**
   - Place your resume PDF in the folder (e.g., `Prerana_Patil_Resume.pdf`).
   - In [`index.html`](file:///c:/Users/Prerna/Desktop/prerana%20patil/index.html#L61), change `href="#contact"` to `href="Prerana_Patil_Resume.pdf" download`.

3. **Social Links & Email:**
   - Replace `https://linkedin.com` with your real LinkedIn profile URL.
   - Replace `https://github.com` with your real GitHub username profile URL.
   - Replace `preranapatil.work@example.com` with your real personal email.

## 🌐 Free Deployment in 2 Minutes

### Free on GitHub Pages:
1. Create a new GitHub repository named `portfolio` or `<your-username>.github.io`.
2. Push `index.html`, `style.css`, and `script.js` to the repository.
3. In GitHub, go to **Settings** > **Pages** > Select `main` branch > **Save**.
4. Your website will be live at `https://<your-username>.github.io`!

### Free on Netlify or Vercel:
- Simply drag-and-drop this entire folder onto [Netlify Drop](https://app.netlify.com/drop) or import from GitHub into [Vercel](https://vercel.com).
